Meezan – MVP Feature Lock
IN SCOPE (v1):
- One portfolio per user
- ERC-20 only
- WBTC + Stablecoin (ETH optional later)
- Risk-based presets
- Optional advanced allocation
- Manual rebalancing trigger (user-initiated)
- Non-custodial vault model
- Simple notifications
- Easy withdrawals
OUT OF SCOPE (v1):
- Multiple portfolios
- Yield / staking
- AI optimisation
- Automatic keepers
- Mobile apps
- Governance
- Token launch
- Social features
